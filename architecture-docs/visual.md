# Identidade e Design Visual

## Temas e Cores
O projeto deve possuir uma estética extremamente profissional e moderna, focada em produtividade.
- **Cores Principais:** Roxo vibrante como cor de destaque (accent color).
- **Dark Mode:** O padrão do aplicativo. Tons de cinza escuro, quase preto, para minimizar a fadiga visual durante edições prolongadas. Fios roxos interconectando nós.
- **Light Mode:** Suporte completo para tema claro, usando fundos brancos ou cinza super claros, com as conexões e botões de destaque mantendo o roxo característico.

## Estrutura da Interface
1. **Menu Lateral Esquerdo:** Biblioteca de nós (Input, Ajustes, Filtros, Processamento) e explorador de arquivos/fluxos.
2. **Canvas Central:** Uma área infinita com um sistema de *grid* (pontos) onde os nós são arrastados e conectados. Deve suportar Pan e Zoom.
3. **Painel de Propriedades (Direita):** Ao clicar em um nó, este painel exibe seus parâmetros específicos (sliders, text inputs, caixas de seleção).
4. **Sistema de Abas:** No topo do Canvas, permitindo o usuário alternar entre diferentes fluxos abertos, similar ao navegador web ou VSCode.
